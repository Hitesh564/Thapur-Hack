## Engine
- 2026-11-21 — Behaviour draws (stay, watch, like, comment, save, share) read `U[0, v, d]`, the viewer's personal dice, whichever round the viewer is exposed in. Distribution draws (accept, tiebreak, select) read `U[t, v, d]`. — Strongest common-random-number pairing: a viewer faces the same dice in both arms even if exposed in different rounds. Still viewer-indexed only.
- 2026-11-21 — Added draw type `select` (Gumbel-top-k keys) next to `tiebreak` (uniform choice, fan-out order). — Avoid reusing one uniform for two correlated choices.
- 2026-11-21 — In the expansion score, `watchfrac_t` is the mean watch fraction among viewers who stayed; stay, like and share rates are per exposed viewer. — Matches RoundMetrics.mean_watch_fraction and keeps S_t near S0 for mid-range videos.
- 2026-11-21 — Graph generated with NumPy (degree-corrected SBM: Poisson follow counts, influence-weighted targets) instead of NetworkX. Edge `u→v` means v follows u. — Faster (~30 ms), same model, no extra conversion.
- 2026-11-21 — Bridges: `bridge_pct` of viewers get `bridge_extra_edges` cross-community followers; the bridge *role* is then computed as top `bridge_pct` non-hubs by cross-community follower fraction. — Reuses existing config keys.
- 2026-11-21 — A follower reached by several sharers in one round is credited to the lowest sharer id; the per-sharer `fanout_cap` is applied before dedupe. — Deterministic and viewer-indexed.
- 2026-11-21 — Share exposures, then the rec batch, are truncated to the remaining exposure budget. — Budget is a hard cap.
- 2026-11-21 — The low-signal stop ends the whole run, including the share channel. — PRD §9.5 lists it as a stop condition for the run.
- 2026-11-21 — Summary `depth` = longest share chain (number of share hops). — Distinguishes from `rounds`.
- 2026-11-21 — Experiments run single-process: 30 seeds × 10 samples × 2 arms ≈ 12 s. — A7 target met without multiprocessing.

## Audience
- 2026-11-21 — Archetype traits limited to attention and like/comment/save/share tendencies. — Novelty and watch tendencies are not used by the behaviour formulas.
- 2026-11-21 — `data/archetypes.json` is a copy of the hand-written fallback (`scripts/build_fallback_archetypes.py`) until LLM generation (D4) is done. — App works offline from the start.
- 2026-11-21 — Trait noise is multiplicative `(1 + N(0, trait_noise))`, clipped at ±`trait_noise_clip` sd. Influence = Pareto(alpha) × influence-class multiplier. — Bounded noise, heavy-tailed influence.

## Lab and diagnostics
- 2026-11-21 — R diagnosis is computed from the event log only, pooling rounds that have a following round (the last round's onward spread is unobserved). Per-community R reports share factors; recommendation is reported run-wide. — Honest identity on the log; rec exposures are not caused by a community.
- 2026-11-21 — The `exposures_per_sharer` factor is skipped when there are no sharers (undefined); `share_given_stay` = 0 is then binding. — Avoid a meaningless 0/0.
- 2026-11-21 — Assumption sample: every ranged parameter uniform in [min, max]; `p` = min + u·(max − min) of the prior ensemble, with the same `u` for both arms. Hypothetical variant adds `prior.hypothetical_delta`, then clips. — Matched draws across arms.
- 2026-11-21 — Sensitivity = Spearman correlation between each sampled parameter (and `p`) and the per-sample median paired difference. — One point per assumption sample.
- 2026-11-21 — Ledger metric names for prior results use the `prior_result.` prefix. — Keeps them distinct from `prior.*` config keys.

## Video, prior, relevance (workstream D)
- 2026-11-21 — VLM provider: OpenAI. Model `gpt-6.2-sol` (newest model on the account that passed a vision + JSON probe), fallback `gpt-5.5`; `gpt-6.2-astra` rejected (failed the colour probe). Transcription: `gpt-4o-transcribe`. All in `config.yaml` → `vlm`. — User asked for the best model regardless of cost.
- 2026-11-21 — API key read only from `OPENAI_API_KEY` (process env, or the Windows user environment via the registry). `VIRALYST_OFFLINE=1` forces every fallback. — Key never in files; offline path testable.
- 2026-11-21 — VLM responses use JSON mode and are validated with Pydantic (not strict structured outputs). One retry per model on invalid JSON, then next model, then fallback. — Rubric keys come from config, so a dynamic validator is simpler.
- 2026-11-21 — Rubric samples (3) and the analysis call run in parallel threads. — ~25 s per new video instead of ~90 s.
- 2026-11-21 — Embedding model: open_clip `ViT-L-14` / `datacomp_xl_s13b_b90k`, CPU. Text template "a short video about {phrase}". — Strongest zero-shot open model that runs on CPU for a few frames.
- 2026-11-21 — `relevance.cos_lo/cos_hi` set to 0.05 / 0.22 by inspection on the test videos (ViT-L cosines: matched archetypes 0.15–0.20, unrelated 0.00–0.07). — PRD says tune by inspection.
- 2026-11-21 — Keyword fallback relevance: strength-weighted word overlap between interest phrases and the video's text fields, plus a category match term, through the same formula with lo=0, hi=1. — Works with no network and no CLIP.
- 2026-11-21 — No PySceneDetect / system ffmpeg: cuts from HSV-histogram change at `cut_scan_fps`; ffmpeg binary from `imageio-ffmpeg`. — Fewer install steps on Windows.
- 2026-11-21 — Heuristic prior formula documented in `app/prior/prior.py`, weights in `prior.heuristic`. Ensemble = [p − spread, p, p + spread]. — Robustness loop still has a spread to sample.
- 2026-11-21 — Test media generated with `gpt-image-2` + `gpt-4o-mini-tts` (`scripts/make_test_media.py`): cooking video with a weak (empty bowl) vs strong (cheese pull) opening, and a gaming video. — Original, license-free fixtures for sanity layer 2 and dev demo. The real demo video is still needed.
- 2026-11-21 — `VIRALYST_CACHE_DIR` overrides the cache folder (tests use a temp dir). Runs' event logs are kept in memory (last 64) for `/events`; payloads are saved as JSON.

## Backend completion (round 3)
- 2026-11-21 — Archetypes generated once by `gpt-6.2-sol` (`python -m app.personas.generate`), validated (50 total, 5–8 per community, 3–6 interests, trait bounds from `personas.*`, sensitive-word blocklist), with up to 3 attempts that feed validation errors back. Fallback file unchanged. — PRD §7.1.
- 2026-11-21 — Relevance results carry the population version; `get_analysis` recomputes relevance if the population changed (CLIP image vectors are cached). — Regenerating personas must not leave stale relevance.
- 2026-11-21 — Population (Parquet) and graph (NPZ + meta JSON) persisted under `cache/world/` by version.
- 2026-11-21 — Event logs persisted as Parquet per run; `/events` reads memory first, then Parquet.
- 2026-11-21 — Exposures-per-sharer breakdown: followers per sharer × unseen fraction × acceptance × cap-and-overlap (exact; counts recorded by the engine per round).
- 2026-11-21 — Pathway priority follows PRD §11.4 order. Hub/bridge-driven = share of *share-channel* exposures sent by hubs/bridges. Cross-community additionally needs `cross_community_min_fraction` (0.3) of share exposures to cross, because the graph's baseline cross share is 0.2 and almost any cascade touches 3 communities.
- 2026-11-21 — Tipping curve: main curve with default assumptions (PRD), plus `points_uncertain` where each seed draws its own assumption sample (`tipping.sample_assumptions`). With defaults the curve is a near-cliff around p ≈ 0.45–0.5 (growth hinges on S vs S0); across assumption ranges it is gradual. Both shown.
- 2026-11-21 — Attention timeline: 8 windows × `video.attention_samples` (2) rubric calls; change within the baseline ensemble's noise is flagged; message names both the supporting and the "drag" window.
- 2026-11-21 — Mini backtest: harness + empty `data/backtest_pairs.csv`; pairs are collected by hand (local files + public view counts). Rating ties count 0.5. Not run yet — needs data.

## Frontend
- 2026-11-21 — React 19 + Vite 8 + TypeScript, no UI/chart libraries: charts are hand-built SVG (line with crosshair tooltip, column/stacked/diverging, horizontal bars with reference line, segmented bar), each with a table view; the cascade replay is a canvas. — Full control over mark specs, small bundle (~86 kB gzip).
- 2026-11-21 — Colours from the dataviz skill's validated reference palette, light + selected dark. Channels use the first three categorical slots (rec = blue, share = orange, seed = aqua), validated all-pairs; aqua is < 3:1 on light, so channel legends are always shown. Diverging blue/red for signed effects; status colours with icon + label for Robust/Likely/Inconclusive.
- 2026-11-21 — Opening Replay or Diagnosis auto-runs the baseline simulation, so the demo path is 6 clicks: video → Replay → Diagnosis → Lab → Run experiment → Ledger.
- 2026-11-21 — Lab defaults the alternate clip to an analysed video with the same topic (else highest prior). Paired-difference histogram shows exact ties as their own grey bar.
- 2026-11-21 — Backend additions for the UI: `GET /world/layout` (deterministic community-cluster layout), `GET /simulations/{id}/cascade` (compact per-exposure arrays), thumbnails/topic/prior in `GET /videos`, community names in bottleneck messages.
- 2026-11-21 — `.claude/launch.json` runs both servers (backend via `python -m uvicorn --app-dir backend`).
